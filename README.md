O **Verifiq** é um aplicativo mobile desenvolvido para combater a desinformação. Ele utiliza inteligência artificial e integração com APIs de checagem para analisar textos, links, imagens e áudio (via microfone) em tempo real.

## 🚀 Funcionalidades Planejadas
- 🎙️ **Checagem por Áudio:** Captura de voz em tempo real via microfone.
- 🔗 **Análise de Links e Textos:** Verificação rápida de notícias e boatos.
- 🖼️ **Busca Reversa de Imagens:** Identificação de contexto e origem de fotos.
- 📊 **Score de Confiabilidade:** Veredito visual (Veridadeiro, Falso, Fora de Contexto).

## 🛠️ Tecnologias
- **Frontend:** Flutter / React Native
- **Backend:** Node.js / Serverless
- **APIs:** Google Fact Check Tools, OpenAI/Gemini, Speech-to-Text
